# **App Name**: AmorPOS

## Core Features:

- Simple POS: Intuitive Point of Sale (POS) interface for quick transaction processing at Panadería Amores.
- Inventory Tracking: Real-time inventory tracking to monitor stock levels of baked goods and ingredients.
- Sales Report Tool: Sales reporting to view daily, weekly, and monthly sales trends. The LLM will be a tool used to highlight items for inventory adjustment.
- Spanish Localization: User-friendly interface localized in Spanish for ease of use by the staff at Panadería Amores.
- Login: Enable users to log in/out of the application to enable security

## Style Guidelines:

- Primary color: Rich red (#8B0000), evoking the passion and love in Panadería Amores.
- Background color: Clean white (#FFFFFF), providing a fresh and modern feel.
- Accent color: Warm brown (#A67B5B) reminiscent of chocolate, for key actions and highlights.
- Classic, readable fonts, prioritizing clarity and ease of use for all staff.
- Simple, easily recognizable icons representing bakery items and POS functions.
- Clean, intuitive layout optimized for quick navigation and minimal training.
